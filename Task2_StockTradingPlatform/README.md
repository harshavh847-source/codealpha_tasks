# Task 2 - Stock Trading Platform

A Java Swing-based stock trading simulation platform developed for the CodeAlpha Java Programming Internship.

## Features

- Stock market simulation
- Buy and sell stocks
- Portfolio management
- Available balance tracking
- Portfolio valuation
- Profit/Loss calculation
- Profit/Loss percentage
- Transaction history with date and time
- Simulated market price updates
- Portfolio summary
- Input validation

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- HashMap and LinkedHashMap
- Collections
- LocalDateTime
- GUI tables and dialogs

## Project Structure

- `Stock.java` - Stock model
- `StockMarket.java` - Available market stocks
- `Portfolio.java` - Portfolio management and calculations
- `Transaction.java` - Transaction history records
- `StockTradingPlatform.java` - Main Swing GUI

## How to Run

1. Open the project in IntelliJ IDEA.
2. Use JDK 21 or a compatible Java version.
3. Open `StockTradingPlatform.java`.
4. Run the `main()` method.
5. Use BUY, SELL, and Update Market features.
