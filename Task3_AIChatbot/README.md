# Task 3 - AI Chatbot

A Java Swing-based AI Study Chatbot designed to provide basic programming assistance through an interactive graphical user interface.

## Features

- Interactive chatbot conversation
- Java programming questions
- OOP concept explanations
- ArrayList explanation
- Current date and time
- Quick topic buttons
- User and chatbot message bubbles
- Message counter
- New Chat option
- Input validation
- Modern graphical user interface

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- LocalDate
- LocalTime
- DateTimeFormatter

## Files

- `AIChatbot.java` - Main graphical user interface and chat functionality
- `ChatbotEngine.java` - Chatbot response and question-processing logic

## How to Run

1. Open the project in IntelliJ IDEA.
2. Use JDK 21.
3. Run `AIChatbot.java`.
4. Type a question or select a topic from the sidebar.
5. The chatbot will generate a response.
