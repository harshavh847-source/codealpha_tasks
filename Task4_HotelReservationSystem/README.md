# Task 4 - Hotel Reservation System

A Java Swing-based Hotel Reservation System developed during my CodeAlpha Java Programming Internship.

## Features

- Guest registration
- Room selection
- Single, Double and Suite rooms
- Room availability tracking
- Booking ID generation
- Multiple-night booking
- Automatic bill calculation
- Booking cancellation
- Active reservation display
- User-friendly graphical interface

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- ArrayList
- Exception Handling

## Project Files

- `Room.java` - Manages room details and availability
- `Guest.java` - Stores guest information
- `Reservation.java` - Handles reservation and billing details
- `HotelManager.java` - Manages rooms and reservations
- `HotelReservationSystem.java` - Main GUI application

## How to Run

1. Open the project in IntelliJ IDEA.
2. Use JDK 21.
3. Run `HotelReservationSystem.java`.
4. Enter guest details.
5. Select an available room.
6. Enter the number of nights.
7. Click **BOOK ROOM**.
8. Use **CANCEL BOOKING** to cancel a reservation.
