# CodeAlpha Tasks

This repository contains the tasks completed during my CodeAlpha Java Programming Internship.

## Task 1 - Student Grade Tracker

A Java Swing-based desktop application for managing student records and analyzing academic performance.

### Features

- Add student records
- Update student information and marks
- Search students by roll number
- Delete student records
- Calculate average marks
- Automatic grade calculation
- PASS/FAIL status
- Class average
- Top student analysis
- Lowest student analysis
- Input validation
- Duplicate roll-number prevention
- Graphical User Interface

### Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- ArrayList
- Arrays
- Comparator and Java Streams

### Files

- `Student.java` - Student details and grade calculations
- `StudentManager.java` - Student record management
- `StudentGradeTracker.java` - Graphical user interface
